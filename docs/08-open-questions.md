# Open questions

The plan was written without the owner in the room, so it rests on defaults.
This file lists every decision that only the owner can make and every fact that
only a lawyer, an accountant or a supplier can confirm. Each entry gives the
default the plan currently assumes, why it matters, and what changes if the
answer is different. Nothing here blocks reading the rest; several entries
block Phase 1 of the [roadmap](01-product/roadmap.md).

**Who answers:** O = owner · L = lawyer · A = accountant · S = supplier or
partner.
